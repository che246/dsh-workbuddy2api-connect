# v0.4.0

**面板上可以选模型了**：每条路由卡里多一个「模型选择」，勾选哪些模型要接进 DSH。

## 新增：模型选择

- 每张路由卡里一个可折叠的 **「模型选择（启用 N / 共 M）」**，展开后逐个列出网关返回的模型
- **勾选 = 启用**；行尾标出要点：上下文 / 思考档 / 可关思考 / 图片 / 倍率
- `全选` / `全不选`，以及关键字过滤（模型多时按 id 或名字搜）
- 未勾选的模型进宿主的 `exclude` 列表，**不注册进 DSH**；一个都没勾会给出「分组会是空的」警告
- 保存即热重注册，不需要重启

设计取舍：用**排除**（`exclude`）而不是白名单。网关新增模型时默认可用，不会被一份过期的白名单挡在外面；想全启用就是全部勾上（等价 `exclude: []`）。

## 宿主侧

- `GET /status` 每条路由新增 `catalog`（逐条模型的 `id` / `contextWindow` / `maxTokens` / `reasoning` /
  `efforts` / `off` / `images` / `rate`）与 `exclude` / `enabled`；`models` 仍是总数，旧界面不受影响
- `exclude` 清洗加固：去重、丢弃非字符串 / 空串 / 超过 200 字符 / 含换行的项，上限 2000 条
- 过滤发生在 `piModels()` 里，即**注册给 pi-ai 的模型表**本身就少了那些条目——不是只在界面上隐藏
